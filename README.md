# الفشّار 🤥: دليل التشغيل

اللعبة فيها شاشتين: **شاشة المذيع** (`index.html`) ودي اللي هتعملها شير سكرين، و**شاشة اللاعب** (`play.html`) ودي اللي بتفتح على موبايلات الناس لما يمسحوا الـ QR.

---

## ⏱ الخطوة 0: جرّب اللعبة لوحدك الأول (دقيقتين)
مش محتاج Firebase ولا GitHub عشان تجرّب.
1. فك الضغط عن الفولدر.
2. افتح `index.html` على Chrome. هتلاقي فوق شارة برتقاني مكتوب عليها **"وضع التجربة"**.
3. انسخ اللينك اللي تحت الـ QR، وافتحه في **3 تابات جديدة في نفس المتصفح**. كل تاب هيبقى لاعب.
4. العب جولة كاملة وانت بتنقل بين التابات.

> وضع التجربة شغال على نفس المتصفح بس. عشان الموبايلات تدخل لازم تكمّل الخطوات اللي جاية.

---

## 🔥 الخطوة 1: Firebase (حوالي 5 دقايق، مجاني)
ده اللي بيوصّل موبايلات الناس بشاشتك لايف.
1. ادخل على **console.firebase.google.com** بأكاونت جوجل ← **Create a project** ← اكتب أي اسم (مثلاً `fishar`). Google Analytics مش محتاجه، اقفله.
2. من القايمة اللي على الشمال: **Build ← Realtime Database ← Create Database**.
   - Location: اختار أي واحدة (مثلاً `europe-west1`).
   - اختار **Start in test mode** ← Enable.
3. افتح تبويب **Rules** وحط الكود ده مكان اللي موجود، وبعدين دوس **Publish**:
   ```json
   {
     "rules": {
       "rooms": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }
   ```
   (من غير الخطوة دي، test mode بيقفل لوحده بعد 30 يوم.)
4. دوس على ⚙️ **Project settings** ← انزل لتحت لحد **Your apps** ← دوس على أيقونة الويب **`</>`** ← اكتب أي اسم ← **Register app**.
5. هيظهرلك كود فيه `const firebaseConfig = { ... }`. انسخ القيم وحطها في ملف **`js/config.js`** مكان الخانات الفاضية.
   - ⚠️ اتأكد إن **`databaseURL`** موجود. لو مش ظاهر، خده من صفحة Realtime Database: هو اللينك اللي فوق، وشكله كده `https://xxxx-default-rtdb.europe-west1.firebasedatabase.app`.

---

## 🐙 الخطوة 2: GitHub Pages (حوالي 3 دقايق)
1. ادخل **github.com** ← **New repository** ← اسمه مثلاً `fishar` ← خليه **Public** ← Create.
2. دوس **"uploading an existing file"** واسحب **كل اللي جوه الفولدر** (`index.html` و`play.html` و`css` و`js` و`README.md`) ← **Commit changes**.
   - ⚠️ ارفع **المحتوى** نفسه، مش الفولدر كله جوه فولدر. لازم `index.html` يبقى في أول الريبو.
3. **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)` ← Save**.
4. استنى دقيقة أو اتنين، وبعدين اللعبة هتبقى على: `https://اسمك.github.io/fishar/`

> لو عدّلت أي ملف بعدين (زي `config.js`)، ارفعه تاني بنفس الطريقة، والموقع بيتحدث لوحده في خلال دقيقة.

---

## ✅ الخطوة 3: بروفة حقيقية (قبل الميتينج بيوم)
- افتح اللينك على اللابتوب. المفروض **ما يظهرش** "وضع التجربة".
- امسح الـ QR من موبايلك، ولو تقدر من موبايل تاني (واحد أندرويد وواحد آيفون).
- العب جولة كاملة.
- جرّب الشير سكرين: في **Google Meet** اختار **"A tab"** مش "Entire screen"، وفعّل **"Also share tab audio"** عشان الأصوات توصل. في **Zoom** فعّل **"Share sound"**.

---

## 🎙 يوم الميتينج
1. افتح `https://اسمك.github.io/fishar/` واعمل شير للتاب.
2. أول ما تفتح هيبقى فيه **لعبة جديدة بكود جديد** جاهزة. ولو عملت refresh هترجع لنفس اللعبة.
3. الناس تمسح الـ QR أو تفتح اللينك، وتكتب أساميها. وانت **ما تلعبش** لإنك عارف الإجابات.
4. دوس **"يلا نبدأ 🚀"** وامشي مع الشاشة.

### الأزرار اللي فوق
| الزرار | بيعمل إيه |
|---|---|
| **+15 ثانية** | يزوّد الوقت لو الناس لسه بتكتب |
| **خلّص دلوقتي ⏭** | يقفل المرحلة على طول |
| **سؤال تاني 🔄** | لو حسيت إن حد عارف المعلومة، يبدّلها بسؤال احتياطي |
| **🔊 / 🔇** | الصوت |
| **🆕** | لعبة جديدة من الصفر (دوس مرتين) |
| **التالي ⏭** (الزرار الأصفر الكبير تحت) | الكشف ما بيتحركش غير لما تدوسه: كل إجابة بتظهر الأول مع اللي اختاروها، ودوسة كمان تكشف «كدبة!» ومين كتبها ونقطه. زرار المسافة أو الأسهم أو ريموت البريزنتيشن بيدوسوه برضه |

### القواعد اللي جوه اللعبة (للعلم)
- **كل واحد صدّق كدبتك = +2**، و**لقيت الحقيقة = +1**. (الكدب أهم من الحقيقة)
- **قبل ما تبدأ:** في الشاشة الأولى زرار **📖 إزاي نلعب؟** بيفتح شرح بالصور (مثال الكاتشب) تقلّبه بالأسهم أو المسافة، وEsc يقفله.
- **عدد الأسئلة مرن:** المقترح 5. بعد كل سؤال، شاشة الترتيب فيها 3 اختيارات: **السؤال الجاي ⏭** أو **آخر سؤال (النقط ×2) 🔥** أو **ننهي هنا ونعلن النتيجة 🏁**. أي اختيار منهم بيوصل لشاشة الجوايز والبطل، كأن اللعبة خلصت عادي.
- **من تاني سؤال «👑 اصطاد المتصدر»:** لو المتصدر صدّق كدبتك تاخد **+3 بونص**.
- **آخر سؤال:** كل النقط **×2**. وبعده لو الناس عايزة تكمل فيه زرار **"سؤال زيادة"**.
- لو حد كتب الإجابة الصح بالغلط، اللعبة بتقوله يغيّرها.
- لو اتنين كتبوا نفس الكدبة، بيتدمجوا والاتنين ياخدوا النقط.
- اللي كتب كدبة وما داسش "ابعت"، كدبته بتتبعت لوحدها لما الوقت يخلص.
- لو حد عمل refresh أو النت قطع، بيرجع بنفس اسمه ونقطه.

## 🗣 سكريبت المذيع (قول بالراحة وبحماس 😄)
- **البداية:** "صباح الخير يا جماعة! قبل الميتينج عندنا 10 دقايق فشر رسمي 😄 امسحوا الـ QR أو افتحوا اللينك واكتبوا أساميكم."
- **قبل أول سؤال:** "هقولكم معلومة غريبة بس حقيقية 100%، وفيها كلمة ناقصة. كل واحد يكتب كدبة لو حد قالهاله هيصدقها."
- **وهما بيكتبوا:** "عايز كدبة تخلّي زمايلك يقعوا فيها… عشر ثواني!"
- **وقت الاختيار:** "قدامكم حقيقة واحدة بس… والباقي فشر زمايلكم. اللي يلاقي الحقيقة ياخد نقطة، واللي يضحك على حد ياخد نقطتين."
- **الكشف:** اقرا كل كدبة بصوت عالي بدراما: "'الكناغر'… مين صدّق دي؟ … اتنين! 😱 ومين الفشّار؟ …"
- **قبل الحقيقة:** "والحقيقة يا جماعة… 🥁"، وبعد ما تظهر احكي القصة في سطرين (تحت).
- **من تاني سؤال:** "المتصدر دلوقتي فلان 👑 اللي يضحك عليه ياخد 3 نقط زيادة. اصطادوه!"
- **آخر سؤال:** "آخر سؤال… والنقط دبل! أي حد لسه يقدر يكسب."
- **قبل الكشف:** "افتحوا المايكات عايزين نسمع الصدمة!"

### قصص الإجابات
قصة كل إجابة بتظهر لوحدها على كارت الحقيقة (💡) عشان تقراها للناس. ولو حابب تعدّلها، هتلاقيها في `js/questions.js` في خانة `story`.

---

## ✏️ تعديل الأسئلة
الأسئلة في **`js/questions.js`**. أول 3 أسئلة هما الأساسيين، والباقي احتياطي. كل سؤال جواه:
- `prompt`: الجملة، والفراغ بيتكتب `____`
- `truth`: الإجابة الصح
- `accept` و`keywords`: الصيغ اللي تتعتبر "كتب الحقيقة"
- `decoys`: كدبات احتياطي بتظهر بس لو الكدبات أقل من 3

## ⚙️ اختيار الأسئلة وترتيبها
- زرار **⚙️ الأسئلة** فوق (وفي الشاشة الأولى) بيفتح نافذة فيها كل الأسئلة.
- علّم على الأسئلة اللي عايزها ورتّبها بـ ▲▼ أو بالسحب. آخر سؤال متعلّم عليه هو «آخر سؤال ×2».
- اللي مش متعلّم عليه بيبقى احتياطي لـ «سؤال تاني 🔄» و«سؤال زيادة 🔁».
- الإجابات مستخبية في النافذة، وفيه زرار يظهرها (متفتحهاش وانت عامل شير).
- الاختيار بيتحفظ في المتصفح.
